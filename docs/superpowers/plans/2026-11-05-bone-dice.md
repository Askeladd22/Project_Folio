# Bone Dice Implementation Plan

> Execution uses superpowers:executing-plans.

**Goal** Apply the approved aged-bone dice appearance to the playable g3d D6 and shelf portraits.

**Architecture** Use the existing ivory shader to draw deterministic bone albedo and ring-and-dot pips from each physical face value. Share material configuration between table and portraits.

**Tech Stack** Lua, LÖVE 11.x, g3d, GLSL and GitHub Actions.

**Spec** User-approved photographic dice reference and the base opposite-face pairs 1/6, 2/5, 3/4. The existing engraved build intentionally replaces its 2 with 1.

## Constraints

- Keep the physical face map, scoring, body geometry and random stream authoritative.
- Retain existing diagnostic material modes and D8 face colors.
- Use subtle matte cream/honey patina and incised dark ring-and-dot pips.
- Keep the existing visual bevel and derive shelf portraits from actual physical orientation.
- Verify through GitHub Actions because the local execution environment is unavailable.

- Graphics state and resource cleanup on render errors.
