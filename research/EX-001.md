# EX-001 — frozen pre-pilot protocol (9 November 2026)

Research question RQ-001: does replacing Merchant V4's automatic opening-X win with a redraw improve player agency without weakening the Merchant?

Reference commit: 8dfa7c87da96afa25d16df11899acada92aac5b3, branch experiments/ex001-merchant-opening-x.

Hypothesis H0: removing automatic outcomes does not substantially improve meaningful player decisions or Merchant agency. H1: B preserves a competitive duel while creating more actionable decisions.

A = original V4. B = redraw opening X from the same box until two numeric offers. All other rules remain fixed, including Merchant counteroffer bust, Farkle selection and hot dice, fixed ante, bankroll, winning criteria, no voluntary raises for the benchmark.

PRE-REGISTERED pilot: seeds 1000 through 1999 inclusive, per arm and per policy. Confirmation seeds 2000–6999 reserved, not run in the pilot. Controls: prudent 30, balanced 50, daring 80, plus random_legal which uniformly chooses a valid selection and banks/takes with equal probability when legal. Merchant policy unchanged. Separate seeded random streams for dice, box and random_legal choices.

Technical gates: original default compatibility; exactly two numeric opening tokens in B; unchanged first two draws at same seed; one payout per hand; same Merchant counteroffer-X behavior; no negative balances and exactly 480 denari across artist+merchant+pot; deterministic repeat; guard against 400+ state transitions.

Primary measured dimensions: opening-X frequency, percentage of hands with a player action, total voluntary selections, Merchant counteroffers, bank balances, matches, reasons for winning, insolvent matches, duration. Wilson 95% for each arm and paired differences by seed with approximate 95% intervals; the raw CSV permits bootstrap later. Beware: counting mandatory roll actions is not synonymous with meaningful choice.

HALT on invariants violation, infinite cycle, bad payouts, or nonrepeatable states. Do not infer human comprehensibility, fairness or preference from scripted win rate. A/B also changes residual type-box composition, not only the automatic-win branch.

G2 only after code and test checks. G3 requires full pilot review, exploit testing and independent holdout protocol. G4 playtesting is still pending. G5 promotion never automatic. No src/ or main edits.
