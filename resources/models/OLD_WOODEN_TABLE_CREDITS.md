# Old Wooden Table — provenienza e condizioni di utilizzo

**Modello fornito dall'utente:** `old_wooden_table__game_ready_asset.glb`
**Attribuzione rilevata nella precedente ispezione:** *Old Wooden Table*, Alex Krush.
**Licenza dichiarata dai metadati dell'asset:** CC BY 4.0.

Il file GLB originale viene consegnato separatamente con la
struttura di installazione `resources/models/old_wooden_table_game_ready_asset.glb`;
**non è incluso nel repository GitHub**. Prima di distribuire il gioco
commercialmente verificare direttamente la pagina originale dell'autore,
la compatibilità degli elementi incorporati e le attribuzioni richieste.

`resources/models/old_wooden_table_fallback.lua` è una **geometria originale
semplificata**, ispirata alla proporzione e struttura del tavolo fornito.
Non è un export dei triangoli né della texture di Alex Krush: serve a
consentire il confronto in-game anche quando il file binario è assente.

La superficie superiore è raccordata alla tavola fisica di Project Folio,
mentre le gambe mantengono una proporzione propria. La mappa colore del
GLB viene usata soltanto quando l'asset originale è installato; il
fallback adotta le texture del progetto. I collider, le fisiche e il
sistema di punteggio dei sei D6 non cambiano.

**Obbligo attribuzione:** mantenere autore, titolo, licenza e modifiche
nei crediti e nelle distribuzioni che contengono il modello originale.
